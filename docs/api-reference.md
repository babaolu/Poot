# CloudMine API Reference

## Orchestrator API

### Miner Registration
`POST /miners/register`

### Miner Heartbeat
`POST /miners/:id/heartbeat`

### Shard Assignment
`POST /shards/assign`

### Instance Deployment
`POST /instances/deploy`

## Customer API

### Deploy Instance
`POST /api/instances`

### Get Instance Status
`GET /api/instances/:id`

### Billing
`GET /api/billing/balance`
